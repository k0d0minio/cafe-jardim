# Jardim Brand Assets

Official brand assets for **Jardim — Café · Galeria**.

For the distilled brand system (colours, type, usage), see the central
[`BRAND.md`](../../../BRAND.md) at the repo root.

## Folder layout

```
brand/
├── guidelines/   Brand deck PDFs (the source of truth)
├── logos/        Logo lockups — png/ (web), jpg/ (flat), source/ (editable), + large-format PDF
├── fonts/        Poppins typeface (18 weights + OFL licence)
├── social/       Social-media profile assets (PNG + editable .ai)
└── documents/    Operational one-off documents (notices, event flyers)
```

## Contents

### `guidelines/`
| File | What it is |
|---|---|
| `jardim-brand-guidelines.pdf` | **Main brand guidelines**, 10 pages — logo, colours, type, graphics |
| `jardim-brand-deck-25.pdf` | Brand deck, 6 pages |
| `jardim-brand-deck-25-alt.pdf` | Alternate version of the 6-page deck (differs from the above) |
| `jardim-brand-deck-25-print.pdf` | Single-page print sheet |

### `logos/`
Six lockups, each in `png/` (hi-res, prefer for web) and `jpg/` (flat):
`jardim-logo-primary-green`, `-mono-white`, `-mono-black`, `-badge-circular`,
`-botanical-cream`, `-botanical-green`.

- `source/jardim-brand.eps`, `source/jardim-brand-package.zip` — editable masters
- `jardim-logo-90x90cm.pdf` — large-format print

### `fonts/poppins/`
Poppins `.ttf` (all weights) + `OFL.txt`. Display / logo typeface. (Roboto — the text
typeface — is not bundled; load it via Google Fonts.)

### `social/`
`jardim-social-networks-01.png`, `-02.png`, and editable `jardim-social-networks.ai`.

### `documents/`
`jardim-closed-today-notice.docx`, `jardim-thanksgiving-flyer.pptx`.

---

> Naming: all files are lowercase kebab-case and prefixed `jardim-`. Keep new assets
> consistent so the folder stays navigable.
